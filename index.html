New in v1.7.3

Full page screenshot & screen capture for Chrome

PageDrop is a free Chrome extension that captures visible tabs, entire scrollable pages, or any region. Annotate, crop, blur sensitive details, and export as PNG, JPEG, or PDF — all with privacy-first activeTab access only.

Add to Chrome — Free Privacy policy

Available on the Chrome Web Store.

Tip: After installing, click the puzzle piece (Extensions) in the Chrome toolbar, then click the pin next to PageDrop so it stays visible for one-click access.

What’s new in v1.7.3

  • No install warnings — PageDrop no longer asks to read your browsing history or access any website
  • Better Scroll & Capture — no duplicate sticky headers, and it now works on infinite feeds (X, Reddit, YouTube) and scroll-snapping pages
  • Clear messages — pages that can’t be captured (Chrome Web Store, New Tab) now explain why instead of failing silently
  • Smoother editor — undo covers text boxes, fixes for crop, highlight and rotate, and much faster editing of long captures

Capture modes

  • Visible tab (Print Page) — screenshot what’s on screen right now
  • Full page (Scroll & Capture) — automatic scrolling capture of long pages with progress indicator; very long pages capture up to ~40 screens for performance
  • Region (Snip Area) — drag to snip any area of the page

Built-in editor

  • Opens in a browser tab so you can review before saving
  • Draw, shapes, arrows, text, and highlight annotations
  • Crop to focus on what matters
  • Blur / redact — permanently pixelate emails, names, or IDs before sharing
  • Feedback — optional note to the developer from the editor toolbar (text only; screenshots never uploaded)
  • Export as PNG, JPEG, or PDF
  • Multi-page PDF when a very long page is split into parts
  • Recent captures history in the session — switch, continue editing, or remove
  • Copy to clipboard, undo/redo, rotate, light/dark theme (follows system)

Privacy-first

  • No install warnings: no browsing-history or website access — activeTab for captures
  • Content script runs only when you start a capture
  • Screenshots stay local until you copy or download
  • No cloud upload of captures; optional Feedback sends only text you submit

Keyboard shortcuts

Customize shortcuts at chrome://extensions/shortcuts.

Windows & Linux

  • Alt+P — Print Page (visible tab screenshot)
  • Alt+G — Scroll & Capture (full page)
  • Alt+S — Snip Area (region)

Mac

  • ⌥P (Option + P) — Print Page
  • ⌥G (Option + G) — Scroll & Capture
  • ⌥S (Option + S) — Snip Area

Frequently asked questions

What is PageDrop?

PageDrop is a free Chrome extension for capturing visible tabs, full scrollable web pages, or custom screen regions. Every capture opens in a built-in editor where you can annotate, crop, blur sensitive details, and export — all processed locally in your browser.

How do I take a full-page screenshot in Chrome?

Install PageDrop, open any normal website, then click the toolbar icon and choose Scroll & Capture, or press Alt+G (Option+G on Mac). PageDrop scrolls automatically and stitches the page into one image.

Keyboard shortcuts not working?

Open chrome://extensions/shortcuts and check that PageDrop has keys assigned for Print Page, Scroll & Capture, and Snip Area. If any shortcut is blank, click it and assign Alt+P, Alt+G, or Alt+S (or your preferred keys). If they still do not work, remove PageDrop and reinstall it so Chrome can apply the defaults again.

Is PageDrop safe and private?

Yes. PageDrop uses activeTab for captures — no browsing-history or website access at install. Screenshots are processed locally and are not uploaded during capture, edit, or export. Optional in-editor Feedback sends only the text (and optional reply email) you choose to submit; screenshots are never attached. See the privacy policy.

Can PageDrop blur or redact sensitive information?

Yes. Drag the blur/redact tool over any area to permanently pixelate emails, names, IDs, or other sensitive content before sharing or exporting.

What file formats does PageDrop export?

PNG (lossless), JPEG (smaller files), and PDF. When a very long page is split into multiple images, you can combine all parts into one multi-page PDF or export the current part only.

What happens on very long full-page captures?

Scroll & Capture stops after about 40 viewport frames so capture stays fast and the editor stays responsive. You’ll see a warning if only the top portion was captured. Use Snip Area for a specific region, or Print Page for one screen.

What pages cannot be captured?

PageDrop cannot capture chrome:// pages, the Chrome Web Store, or the New Tab page. Open a normal website first. Refresh the page once (F5) after installing or updating.
