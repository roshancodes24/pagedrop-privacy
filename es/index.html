PageDrop
Capturas de página completa y de zonas para Chrome

Nuevo en la v1.7.4

Captura de pantalla de página completa para Chrome

PageDrop es una extensión gratuita para Chrome que captura el área visible, páginas completas con desplazamiento o cualquier zona. Anota, recorta, difumina datos sensibles y exporta en PNG, JPEG o PDF — con acceso activeTab, que prioriza tu privacidad.

Añadir a Chrome — Gratis Política de privacidad

Disponible en Chrome Web Store.

Consejo: después de instalarla, haz clic en el icono de la pieza de puzle (Extensiones) de la barra de Chrome y luego en la chincheta junto a PageDrop para tenerla siempre a mano.

Modos de captura

  • Área visible — captura lo que ves en pantalla ahora mismo
  • Desplazar y capturar (página completa) — recorre sola las páginas largas y muestra el progreso; las páginas muy largas se capturan hasta unas 40 pantallas para mantener el rendimiento
  • Recortar área — arrastra para capturar cualquier zona de la página

Editor integrado

  • Se abre en una pestaña del navegador para que la revises antes de guardar
  • Dibujo, formas, flechas, texto y resaltado
  • Recorte para centrarte en lo importante
  • Difuminar / ocultar — pixela de forma permanente correos, nombres o números de identificación antes de compartir
  • Comentarios — nota opcional al desarrollador desde la barra del editor (solo texto; las capturas nunca se suben)
  • Exporta en PNG, JPEG o PDF
  • PDF de varias páginas cuando una página muy larga se divide en partes
  • Historial de capturas recientes — cambia entre ellas, sigue editando o bórralas
  • Copiar al portapapeles, deshacer/rehacer, girar, tema claro/oscuro (sigue al sistema)

Privacidad primero

  • Sin avisos al instalar: sin acceso al historial de navegación ni a sitios web — solo activeTab para las capturas
  • El script de contenido solo se ejecuta cuando tú inicias una captura
  • Las capturas se quedan en tu equipo hasta que las copias o descargas
  • Las capturas no se suben a la nube; los Comentarios opcionales envían solo el texto que escribas

Atajos de teclado

Personaliza los atajos en chrome://extensions/shortcuts.

Windows y Linux

  • Alt+P — Área visible (lo que se ve en pantalla)
  • Alt+G — Desplazar y capturar (página completa)
  • Alt+S — Recortar área (zona)

Mac

  • ⌥P (Option + P) — Área visible
  • ⌥G (Option + G) — Desplazar y capturar
  • ⌥S (Option + S) — Recortar área

Preguntas frecuentes

¿Qué es PageDrop?

PageDrop es una extensión gratuita para Chrome que captura el área visible, páginas web completas con desplazamiento o zonas personalizadas de la pantalla. Cada captura se abre en un editor integrado donde puedes anotar, recortar, difuminar datos sensibles y exportar — todo se procesa localmente en tu navegador.

¿Cómo hago una captura de página completa en Chrome?

Instala PageDrop, abre cualquier sitio web normal, haz clic en el icono de la barra de herramientas y elige Desplazar y capturar, o pulsa Alt+G (Option+G en Mac). PageDrop se desplaza solo y une la página en una sola imagen.

¿No funcionan los atajos de teclado?

Abre chrome://extensions/shortcuts y comprueba que PageDrop tiene teclas asignadas para Área visible, Desplazar y capturar y Recortar área. Si algún atajo está vacío, haz clic en él y asigna Alt+P, Alt+G o Alt+S (o las teclas que prefieras). Si siguen sin funcionar, quita PageDrop y vuelve a instalarlo para que Chrome aplique los atajos predeterminados.

¿PageDrop es seguro y privado?

Sí. PageDrop usa activeTab para las capturas — sin acceso al historial de navegación ni a sitios web al instalarlo. Las capturas se procesan localmente y no se suben durante la captura, la edición ni la exportación. Los Comentarios opcionales desde el editor envían solo el texto (y un correo opcional para responderte) que decidas enviar; nunca se adjuntan capturas. Consulta la política de privacidad.

¿PageDrop puede difuminar u ocultar información sensible?

Sí. Arrastra la herramienta de difuminado sobre cualquier zona para pixelar de forma permanente correos, nombres, números de identificación u otros datos sensibles antes de compartir o exportar.

¿En qué formatos exporta PageDrop?

PNG (sin pérdida), JPEG (archivos más pequeños) y PDF. Si una página muy larga se divide en varias imágenes, puedes unir todas las partes en un solo PDF de varias páginas o exportar solo la parte actual.

¿Qué pasa con las capturas de páginas muy largas?

Desplazar y capturar se detiene tras unas 40 pantallas para que la captura sea rápida y el editor responda con fluidez. Verás un aviso si solo se capturó la parte superior de la página. Usa Recortar área para una zona concreta o Área visible para una sola pantalla.

¿Qué páginas no se pueden capturar?

PageDrop no puede capturar páginas chrome://, Chrome Web Store ni la página Nueva pestaña. Abre primero un sitio web normal. Recarga la página una vez (F5) después de instalar o actualizar.
