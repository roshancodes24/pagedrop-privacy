PageDrop

プライバシーポリシー

最終更新日：2026年11月1日

このページは英語の原文を翻訳したものです。 内容に相違がある場合は、英語版が優先されます。

はじめに

PageDrop は、ウェブページのスクリーンショット（表示範囲、スクロールが必要なページ全体、または選択した範囲）を 撮影し、コピーやダウンロードの前に内蔵エディターで注釈を付けられる Chrome 拡張機能です。

私たちはあなたのプライバシーを大切にしています。本ポリシーでは、PageDrop があなたの情報について何を行い、 何を行わないかを説明します。要約すると、スクリーンショットの撮影と編集はお使いの端末内で完結し、PageDrop が 閲覧行動を追跡したり、キャプチャを当方のサーバーに送信したりすることはありません。

データの収集

PageDrop は、通常の使用において個人データを収集しません。閲覧履歴、アカウント情報、 日常的な拡張機能の利用に関する統計を販売、貸与、共有することはありません。

  • スクリーンショットの撮影、編集、書き出しはブラウザ内でローカルに行われます。
  • PageDrop は Cookie を設定しません。
  • 通常の使用において、分析・トラッキング・広告ツールは使用しません。
  • 任意のエディター内フィードバックと アンインストール時のフィードバックについては後述します。これらのフォームを 送信しない限り、何も送信されません。

スクリーンショットを撮影すると、エディターの履歴パネルから最近のキャプチャにアクセスできるよう、画像は ブラウザのローカルストレージ（IndexedDB）に一時的に保存されます。最近のキャプチャは、削除するまで最大 50 件 保持されます。このデータが端末の外に出ることはなく、拡張機能をアンインストールするか、ブラウザの拡張機能 データを消去すると削除されます。

権限の説明

PageDrop が求めるのは、あなたが明示的にキャプチャを開始したときに、スクリーンショットの撮影と編集に必要な 権限だけです。インストール時に閲覧履歴の読み取りやウェブサイトへのアクセスを求めることはありません。 キャプチャ用の権限が、バックグラウンドで個人データを収集・送信するために使われることはありません。

  • activeTab キャプチャを開始したとき（ツールバーのアイコンをクリックする、キーボードショートカットを使う、 右クリックメニューから項目を選ぶ）に限り、表示中のタブへのアクセスを PageDrop に許可します。 あなたの操作なしに、PageDrop がバックグラウンドでタブにアクセスすることはありません。
  • scripting 必要に応じて、PageDrop のコンテンツスクリプトをアクティブなタブに挿入するために使用します。たとえば、 ページ全体のキャプチャ中にページをスクロールする、範囲選択用のオーバーレイを表示する、ステータス メッセージを表示する、撮影後にページを元に戻す、といった用途です。挿入は、キャプチャを開始したタブで のみ行われます。
  • contextMenus ウェブページの右クリックメニューに「PageDrop」項目を追加し、ツールバーのポップアップを開かずに 「表示範囲をキャプチャ」「スクロールしてキャプチャ」「範囲を選択」をすばやく使えるようにするために使用します。
  • clipboardWrite（任意） エディターでコピーを選んだときにだけ求められます。PageDrop が書き込むのは、あなたが明示的にコピーした 画像だけです。クリップボードの内容を読み取ることはありません。
  • storage 書き出し形式の設定と、エディターのローカルなキャプチャ履歴を保存するために使用します。このデータは 端末内の chrome.storage.local に保存され、どのサーバーにも送信されません。ライト／ダークの 外観はシステム設定に従います。

バージョン 1.7.3 以降、PageDrop はホスト権限を一切求めず（インストール時にどのウェブサイトへの アクセス権も求めません）、tabs 権限も求めません。そのため、ほかのタブのアドレスを 見ることはできません。キャプチャでは、表示中のタブであなたがキャプチャを開始したときにだけ、 activeTab と scripting によるオンデマンドの挿入を使用します。任意のフィードバックは、 [送信] をクリックしたときにだけ Google Apps Script のウェブアプリに送られ、ウェブサイトへのアクセス権は 必要ありません。エディター内フィードバックをご覧ください。

エディター内フィードバック

PageDrop エディターの右側ツールバー（[回転] の下）には、任意のフィードバックボタンがあります。 使うかどうかはあなたが決められ、[送信] をクリックしない限り何も送信されません。

  • フィードバックは、スクリーンショット、閲覧履歴、ページの URL と関連付けられません。 キャプチャが添付・アップロードされることはありません。
  • 当方が受け取るのは、あなたが自発的に送信した内容のみです：メッセージ本文、入力した場合は任意の返信用 メールアドレス、拡張機能のバージョン（問題の診断のため）。
  • メッセージは Google Apps Script のウェブアプリを通じて、開発者の受信トレイ （developerchromextension@gmail.com）に届きます。
  • フィードバックの送信先が設定されていない場合、[送信] を押すと、内容が入力済みの状態でメールアプリが 開くことがあります（この場合も、[送信] を選んだ後に限られます）。

キャプチャ、編集、コピー、ダウンロードに、このフィードバック機能は一切必要ありません。

アンインストール時のフィードバック

PageDrop をアンインストールすると、Chrome が当方の GitHub Pages サイト上にある短い任意のアンケートページを 開くことがあります。回答するかどうかはあなたが決められ、フォームを送信しない限り何も送信されません。

  • フィードバックは、スクリーンショット、閲覧履歴、ページの URL と関連付けられません。
  • 収集するのは、あなたが自発的に送信した内容のみです（例：アンインストールの理由、任意の一言コメント、 任意の 1〜5 の評価、提供を選んだ場合の任意のメールアドレス）。
  • 回答は、PageDrop の改善のためだけに使用する非公開の Google スプレッドシートに保存されます。
  • 拡張機能のバージョンが、匿名のクエリパラメータとしてアンケートページの URL に含まれる場合があります （例：?v=1.7）。

フォームを送信せずにアンインストールした場合、何も送信されません。キャプチャ、編集、書き出しに サーバーとの通信は一切必要ありません。

第三者

PageDrop は、通常の使用において分析プラットフォームや広告ネットワークと連携しません。スクリーンショットの 処理に第三者の API は使用しません。

任意のアンインストール時のフィードバックは Google スプレッドシート（Google のサービス）に保存されます。 任意のエディター内フィードバックは、Google Apps Script／Gmail（Google のサービス）を通じて開発者の受信トレイに 届きます。Google によるこれらのデータの取り扱いには、 Google のプライバシーポリシーが適用されます。

Chrome ウェブストアは Google が運営しています。ストアを通じた PageDrop のインストールや更新には、本ポリシーとは 別の、Google 独自のプライバシーポリシーが適用されます。

本ポリシーの変更

本プライバシーポリシーは随時更新することがあります。更新した場合は、このページ上部の「最終更新日」を 改訂します。変更後も PageDrop を引き続き使用した場合、更新後のポリシーに同意したものとみなされます。

重要な変更（たとえば、PageDrop がユーザーデータの収集を始める場合）を行う際は、このページを更新し、 必要に応じて、変更の発効前に Chrome ウェブストアの掲載情報でユーザーにお知らせします。
