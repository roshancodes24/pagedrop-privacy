v1.7.3 の新機能

Chrome でページ全体のスクリーンショット・画面キャプチャ

PageDrop は、表示中の画面、スクロールが必要な長いページ全体、または任意の範囲をキャプチャできる 無料の Chrome 拡張機能です。注釈を付けたり、切り抜いたり、機密情報をぼかしたりして、 PNG・JPEG・PDF で書き出せます。権限はプライバシーに配慮した activeTab のみです。

Chrome に追加（無料） プライバシーポリシー

Chrome ウェブストアで公開中です。

ヒント：インストール後、Chrome ツールバーのパズルピース（拡張機能）アイコンをクリックし、 PageDrop の横にあるピンをクリックすると、いつでもワンクリックで使えます。

v1.7.3 の新機能

  • インストール時の警告なし — 閲覧履歴の読み取りやウェブサイトへのアクセスを求めなくなりました
  • スクロールしてキャプチャを改善 — 固定ヘッダーが重複しなくなり、無限スクロールのフィード（X、Reddit、YouTube）やスクロールスナップのページにも対応しました
  • わかりやすいメッセージ — キャプチャできないページ（Chrome ウェブストア、新しいタブ）では、黙って失敗せずに理由を表示するようになりました
  • エディターがより快適に — テキストボックスも元に戻せるようになり、切り抜き・ハイライト・回転の不具合を修正。長いキャプチャの編集も大幅に速くなりました

キャプチャ方法

  • 表示範囲をキャプチャ — いま画面に表示されている部分を撮影
  • スクロールしてキャプチャ（ページ全体）— 長いページを自動でスクロールして撮影し、進行状況を表示。非常に長いページは、動作を軽く保つため約 40 画面分までキャプチャします
  • 範囲を選択 — ドラッグしてページの好きな部分を切り取り

内蔵エディター

  • ブラウザのタブで開くので、保存前に確認できます
  • 描画、図形、矢印、テキスト、ハイライト
  • 切り抜きで必要な部分だけに
  • ぼかし／黒塗り — 共有前にメールアドレスや名前、ID をモザイクで完全に隠す
  • フィードバック — エディターのツールバーから開発者に任意でメッセージを送信（テキストのみ。スクリーンショットは送信されません）
  • PNG・JPEG・PDF で書き出し
  • 長いページが複数に分割された場合は、複数ページの PDF にまとめられます
  • 最近のキャプチャ履歴 — 切り替え、編集の続き、削除ができます
  • クリップボードにコピー、元に戻す／やり直し、回転、ライト／ダークテーマ（システム設定に追従）

プライバシー重視

  • インストール時の警告なし：閲覧履歴やウェブサイトへのアクセス権は不要。キャプチャには activeTab のみを使用
  • コンテンツスクリプトは、あなたがキャプチャを開始したときだけ動作
  • スクリーンショットは、コピーやダウンロードをするまで端末内にとどまります
  • キャプチャをクラウドにアップロードしません。任意のフィードバックで送られるのは入力したテキストだけです

キーボードショートカット

ショートカットは chrome://extensions/shortcuts で変更できます。

Windows・Linux

  • Alt+P — 表示範囲をキャプチャ（表示中の画面）
  • Alt+G — スクロールしてキャプチャ（ページ全体）
  • Alt+S — 範囲を選択（指定した範囲）

Mac

  • ⌥P（Option + P）— 表示範囲をキャプチャ
  • ⌥G（Option + G）— スクロールしてキャプチャ
  • ⌥S（Option + S）— 範囲を選択

よくある質問

PageDrop とは何ですか？

PageDrop は、表示中の画面、スクロールが必要なページ全体、または任意の範囲をキャプチャできる無料の Chrome 拡張機能です。キャプチャはすべて内蔵エディターで開き、注釈、切り抜き、機密情報のぼかし、 書き出しができます。処理はすべてブラウザ内で行われます。

Chrome でページ全体のスクリーンショットを撮るには？

PageDrop をインストールし、通常のウェブサイトを開いてから、ツールバーのアイコンをクリックして スクロールしてキャプチャを選ぶか、Alt+G（Mac は Option+G）を押します。 PageDrop が自動でスクロールし、ページ全体を 1 枚の画像につなぎ合わせます。

キーボードショートカットが効かない場合は？

chrome://extensions/shortcuts を開き、PageDrop の「表示範囲をキャプチャ」「スクロールしてキャプチャ」 「範囲を選択」にキーが割り当てられているか確認してください。空欄のものがあればクリックして Alt+P、Alt+G、Alt+S（またはお好みのキー）を割り当てます。 それでも動かない場合は、PageDrop を削除して再インストールすると、Chrome が既定のショートカットを再適用します。

PageDrop は安全ですか？プライバシーは守られますか？

はい。PageDrop はキャプチャに activeTab を使用し、インストール時に閲覧履歴やウェブサイトへの アクセスを求めません。スクリーンショットはローカルで処理され、キャプチャ・編集・書き出しの際にアップロード されることはありません。エディターからの任意のフィードバックで送られるのは、あなたが送信したテキスト（と任意の 返信用メールアドレス）だけで、スクリーンショットは添付されません。詳しくはプライバシーポリシーをご覧ください。

機密情報をぼかしたり隠したりできますか？

はい。ぼかしツールで任意の範囲をドラッグすると、メールアドレス、名前、ID などの機密情報を、 共有や書き出しの前にモザイクで完全に隠せます。

どのファイル形式で書き出せますか？

PNG（劣化なし）、JPEG（ファイルサイズが小さい）、PDF です。非常に長いページが複数の画像に分割された場合は、 すべてを 1 つの複数ページ PDF にまとめるか、表示中のパートだけを書き出せます。

非常に長いページをキャプチャするとどうなりますか？

スクロールしてキャプチャは、撮影を速く、エディターを快適に保つため、約 40 画面分で停止します。 ページの上部しか撮影できなかった場合は警告が表示されます。特定の部分なら範囲を選択、 1 画面分なら表示範囲をキャプチャをお使いください。

キャプチャできないページはありますか？

chrome:// のページ、Chrome ウェブストア、新しいタブのページはキャプチャできません。 先に通常のウェブサイトを開いてください。インストールや更新の後は、ページを一度再読み込み（F5）してください。
