Chrome 网页整页截图与长截图工具

PageDrop 是一款免费的 Chrome 扩展，可以截取当前可见区域、需要滚动的整个网页，或任意选定区域。 你可以标注、裁剪、模糊打码敏感信息，并导出为 PNG、JPEG 或 PDF——只使用隐私优先的 activeTab 权限。

添加至 Chrome — 免费 隐私政策

已在 Chrome 应用商店上架。

小提示：安装后，点击 Chrome 工具栏中的拼图图标（扩展程序），再点击 PageDrop 旁边的图钉，即可将它固定在工具栏上，一键使用。

v1.7.4 新功能

  • 若干小问题修复

  • 编辑器更流畅 — 撤销现在也包括文本框，修复了裁剪、高亮和旋转的问题，编辑长截图也快了很多

截图方式

  • 截取可见区域 — 截取当前屏幕上显示的内容
  • 滚动截长图（整个网页）— 自动滚动长网页并显示进度；为保证性能，超长网页最多截取约 40 屏
  • 框选截图 — 拖动鼠标，截取页面的任意区域

内置编辑器

  • 在浏览器标签页中打开，保存前可以先检查
  • 画笔、形状、箭头、文字和高亮标注
  • 裁剪，只保留重点内容
  • 模糊打码 — 分享前对邮箱、姓名或证件号等进行永久马赛克处理
  • 反馈 — 可在编辑器工具栏中给开发者留言（仅文字，绝不上传截图）
  • 导出为 PNG、JPEG 或 PDF
  • 超长网页被拆分成多张时，可导出为多页 PDF
  • 最近截图历史 — 可切换、继续编辑或删除
  • 复制到剪贴板、撤销/重做、旋转、浅色/深色主题（跟随系统）

隐私优先

  • 安装时无权限警告：不访问浏览历史和网站——截图只使用 activeTab
  • 内容脚本只在你开始截图时运行
  • 截图保存在本地，直到你复制或下载
  • 截图不会上传到云端；可选的反馈只发送你填写的文字

键盘快捷键

可在 chrome://extensions/shortcuts 中自定义快捷键。

Windows 和 Linux

  • Alt+P — 截取可见区域（当前屏幕）
  • Alt+G — 滚动截长图（整个网页）
  • Alt+S — 框选截图（选定区域）

Mac

  • ⌥P（Option + P）— 截取可见区域
  • ⌥G（Option + G）— 滚动截长图
  • ⌥S（Option + S）— 框选截图

常见问题

PageDrop 是什么？

PageDrop 是一款免费的 Chrome 扩展，可以截取可见区域、需要滚动的整个网页或自定义的屏幕区域。 每张截图都会在内置编辑器中打开，你可以标注、裁剪、模糊打码敏感信息并导出——全部在浏览器本地处理。

如何在 Chrome 中截取整个网页？

安装 PageDrop，打开任意普通网页，点击工具栏图标并选择滚动截长图，或按 Alt+G（Mac 上为 Option+G）。PageDrop 会自动滚动，并将整个网页拼接成一张图片。

键盘快捷键不起作用？

打开 chrome://extensions/shortcuts，检查 PageDrop 的“截取可见区域”“滚动截长图”和“框选截图” 是否已设置按键。如果某个快捷键为空，点击它并设置为 Alt+P、Alt+G 或 Alt+S（或你喜欢的按键）。如果仍然无效，请移除 PageDrop 后重新安装，让 Chrome 重新应用默认快捷键。

PageDrop 安全吗？会保护隐私吗？

会。PageDrop 截图时使用 activeTab 权限——安装时不会请求访问浏览历史或任何网站。 截图在本地处理，截图、编辑和导出过程中都不会上传。编辑器中的可选反馈只发送你主动提交的文字 （以及可选的回复邮箱），绝不附带截图。详见隐私政策。

PageDrop 能模糊或隐藏敏感信息吗？

能。用模糊工具拖过任意区域，即可在分享或导出前，对邮箱、姓名、证件号等敏感内容进行永久马赛克处理。

PageDrop 支持导出哪些格式？

PNG（无损）、JPEG（文件更小）和 PDF。超长网页被拆分成多张图片时，可以将所有部分合并为一个多页 PDF， 或只导出当前部分。

截取超长网页会怎样？

为了保证截图速度和编辑器的流畅，滚动截长图在大约 40 屏后会停止。如果只截取了网页的上半部分， 会显示提示。截取特定区域请用框选截图，只截一屏请用截取可见区域。

哪些页面无法截图？

PageDrop 无法截取 chrome:// 页面、Chrome 应用商店或新标签页。请先打开普通网页。 安装或更新后，请刷新页面一次（F5）。
