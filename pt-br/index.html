Print da página inteira e captura de tela para o Chrome

O PageDrop é uma extensão gratuita para o Chrome que captura a área visível, a página inteira com rolagem ou qualquer área que você escolher. Anote, corte, desfoque dados sensíveis e exporte em PNG, JPEG ou PDF — com acesso activeTab, que coloca a privacidade em primeiro lugar.

Adicionar ao Chrome — Grátis Política de privacidade

Disponível na Chrome Web Store.

Dica: depois de instalar, clique no ícone de quebra-cabeça (Extensões) na barra do Chrome e depois no alfinete ao lado do PageDrop para deixá-lo sempre à mão.

Modos de captura

  • Área visível — print do que está na tela agora
  • Rolar e capturar (página inteira) — rola páginas longas automaticamente e mostra o progresso; páginas muito longas são capturadas até cerca de 40 telas, para manter o desempenho
  • Recortar área — arraste para capturar qualquer parte da página

Editor integrado

  • Abre em uma aba do navegador para você revisar antes de salvar
  • Desenho, formas, setas, texto e destaque
  • Corte para focar no que importa
  • Desfocar / ocultar — pixeliza de forma permanente e-mails, nomes ou números de documentos antes de compartilhar
  • Feedback — mensagem opcional para o desenvolvedor pela barra do editor (só texto; os prints nunca são enviados)
  • Exporte em PNG, JPEG ou PDF
  • PDF de várias páginas quando uma página muito longa é dividida em partes
  • Histórico de capturas recentes — alterne entre elas, continue editando ou apague
  • Copiar para a área de transferência, desfazer/refazer, girar, tema claro/escuro (segue o sistema)

Privacidade em primeiro lugar

  • Sem avisos na instalação: nenhum acesso ao histórico de navegação ou a sites — só activeTab para as capturas
  • O script de conteúdo só roda quando você inicia uma captura
  • Os prints ficam no seu computador até você copiar ou baixar
  • Nenhum upload das capturas para a nuvem; o Feedback opcional envia só o texto que você escrever

Atalhos de teclado

Personalize os atalhos em chrome://extensions/shortcuts.

Windows e Linux

  • Alt+P — Área visível (print do que está na tela)
  • Alt+G — Rolar e capturar (página inteira)
  • Alt+S — Recortar área (seleção)

Mac

  • ⌥P (Option + P) — Área visível
  • ⌥G (Option + G) — Rolar e capturar
  • ⌥S (Option + S) — Recortar área

Perguntas frequentes

O que é o PageDrop?

O PageDrop é uma extensão gratuita para o Chrome que captura a área visível, páginas inteiras com rolagem ou áreas personalizadas da tela. Cada captura abre em um editor integrado, onde você pode anotar, cortar, desfocar informações sensíveis e exportar — tudo processado localmente no seu navegador.

Como tirar print da página inteira no Chrome?

Instale o PageDrop, abra qualquer site normal, clique no ícone na barra de ferramentas e escolha Rolar e capturar, ou pressione Alt+G (Option+G no Mac). O PageDrop rola a página automaticamente e junta tudo em uma única imagem.

Os atalhos de teclado não funcionam?

Abra chrome://extensions/shortcuts e confira se o PageDrop tem teclas definidas para Área visível, Rolar e capturar e Recortar área. Se algum atalho estiver em branco, clique nele e defina Alt+P, Alt+G ou Alt+S (ou as teclas que preferir). Se ainda não funcionarem, remova o PageDrop e instale de novo para o Chrome aplicar os atalhos padrão.

O PageDrop é seguro e respeita a privacidade?

Sim. O PageDrop usa activeTab para as capturas — sem acesso ao histórico de navegação ou a sites na instalação. Os prints são processados localmente e não são enviados durante a captura, a edição ou a exportação. O Feedback opcional pelo editor envia só o texto (e um e-mail opcional para resposta) que você decidir mandar; prints nunca são anexados. Veja a política de privacidade.

O PageDrop consegue desfocar ou ocultar informações sensíveis?

Sim. Arraste a ferramenta de desfoque sobre qualquer área para pixelizar de forma permanente e-mails, nomes, números de documentos ou outros dados sensíveis antes de compartilhar ou exportar.

Em quais formatos o PageDrop exporta?

PNG (sem perda de qualidade), JPEG (arquivos menores) e PDF. Quando uma página muito longa é dividida em várias imagens, você pode juntar todas as partes em um único PDF de várias páginas ou exportar só a parte atual.

O que acontece em capturas muito longas?

O Rolar e capturar para depois de cerca de 40 telas, para que a captura continue rápida e o editor responda bem. Você verá um aviso se só a parte de cima da página foi capturada. Use Recortar área para uma região específica ou Área visível para uma única tela.

Quais páginas não podem ser capturadas?

O PageDrop não captura páginas chrome://, a Chrome Web Store nem a página Nova guia. Abra um site normal primeiro. Depois de instalar ou atualizar, recarregue a página uma vez (F5).
